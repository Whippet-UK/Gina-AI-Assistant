# Logs & Audit Trail Directory

This directory stores runtime audit logs, benchmark summaries, and telemetry snapshots for Gina AI Factory.

- Source Code & Historical Logs: `CHANGELOG.md` at project root.
- Persistent Agent Memory: `C:\Gina_AI\.gina\agent-memory.json`.
- System Telemetry & Error Logs: Broadcast in real-time via `/api/telemetry` and `/api/comfy/error-logs`.
