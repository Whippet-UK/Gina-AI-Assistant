# v1.17.85 — ACE-Step Windows uv Bootstrap

## Problem
The v1.17.84 singing installer stopped when `uv` was not already installed.

## Fix
The installer now bootstraps uv with the official Windows PowerShell installer and resolves uv from PATH or its standard Windows install locations. The ACE-Step API launcher uses the same resolution logic.

## Runtime
The singing API remains local-only on `127.0.0.1:8101` and is configured for the 8GB GPU target using the 0.6B LM, PyTorch backend, and CPU offload.
