# v1.17.87 — Fooocus-Inspired Gina Image Studio

## Goal

Rebuild Gina's image-generation workspace around the focused interaction pattern users like in Fooocus: prompt first, essential controls close to the prompt, large unobstructed preview, and secondary controls tucked away.

## Backend safety

The redesign does **not** replace Gina's validated local ComfyUI image lane. The active image workflow remains `flux_image`, using the project's FLUX.1-Schnell GGUF Q4_K_S setup through ComfyUI. AIDA64 1024×600, reference-image handling, seed/advanced controls, VRAM purge, Keep Image, variation, download, and asset saving remain available.

## UX changes

- Dark, compact creation surface with a dedicated preview column.
- Prompt is the primary control.
- Aspect ratio, image size, style, and actual workflow model are visible without opening advanced settings.
- Reference image is presented as a simple local image-input card.
- Negative prompt, advanced controls, and technical workflow details are collapsible.
- Generation progress is displayed inside the preview.
- Post-generation actions stay beside the image: keep/reference, variation, save file, library, and AIDA64 fusion.

## Attribution

The interaction direction is inspired by the publicly available Fooocus project by lllyasviel. Gina's implementation is a native TypeScript/React workspace integrated with Gina's existing ComfyUI backend and project safety rules.

Official reference: https://github.com/lllyasviel/Fooocus
