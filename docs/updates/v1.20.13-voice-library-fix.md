# v1.20.13 — Voice Library / Preview Fix

## What changed

- The Unified Audio Deck now defaults to a real Bark v2 system speaker (`v2/en_speaker_6`) instead of the non-provisioned `Ana Florence` XTTS entry.
- Removed the three phantom XTTS system voices (`Ana Florence`, `Daisy`, `English Male`) from the seeded system library. They had no reference recordings and were not valid XTTS speaker assets.
- Existing installations migrate those phantom records out of the system library on database initialization.
- Bark voice previews now use a longer, speech-focused preview sentence.
- XTTS preview is blocked unless a real reference recording is attached.
- The Python XTTS backend now fails clearly when neither a reference WAV nor an actual model speaker ID is supplied, instead of producing an invalid preview.

## Bark voice source

The Bark system voices are the official Bark history prompts (`v2/en_speaker_0` through `v2/en_speaker_9`). Bark documents these as speaker presets and the upstream implementation validates them as supported history prompts.
