# v1.17.86 — ACE-Step API CLI Fix

## Problem
The ACE-Step Windows launcher was passing Gradio-style underscore/hybrid options to the current `acestep-api` entrypoint. The API server rejected `--init-service true`, `--config-path`, and `--offload-to-cpu` before starting.

## Fix
The launcher now uses the API server's supported command-line flags:

```bat
uv run --no-sync acestep-api --host 127.0.0.1 --port 8101 --init-llm --lm-model-path acestep-5Hz-lm-0.6B
```

The model/offload configuration remains in environment variables so the 8GB-safe settings are preserved. The same corrected launch contract is used by `Start_Factory.bat`.

## Verification basis
ACE-Step's current API documentation distinguishes the API server flags from the Gradio UI flags and documents environment-variable configuration for the API server.
