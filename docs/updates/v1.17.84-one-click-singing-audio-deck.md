# v1.17.84 — One-Click Singing + Audio Deck Pipeline

## Goal

Make Music Studio behave as one complete local workflow: enter lyrics/style/vocal settings, generate the song with a real singing backend, save the WAV into Gina's audio library, and automatically load that WAV into the Audio Deck.

## Changes

- Added ACE-Step 1.5 local REST integration for lyrics-to-song generation.
- Lyrics + vocals now route away from MusicGen to ACE-Step automatically.
- Uses the 0.6B 5Hz LM, PyTorch backend, and CPU offload configuration for the 8GB RTX 3070 Ti target.
- Added vocal language selection.
- Added ACE-Step health status to Music Studio.
- Added explicit Windows setup/start scripts under `scripts/`.
- Generation remains local-only once ACE-Step is installed and running; Gina does not download models during Generate.
- Completed jobs now automatically load their WAV into the Audio Deck.
- Audio element explicitly reloads when the active track URL changes.
- Fixed/retained Windows-safe managed model path normalization and PCM16 WAV writing.

## Intended workflow

1. Run `scripts\Install_ACEStep_Singing.bat` once.
2. Start ACE-Step with `scripts\Start_ACEStep_Singing_API.bat` (or use `Start_Factory.bat` after installation).
3. In Music Studio enter lyrics, style, vocal type, language and duration.
4. Press `Generate Singing Song`.
5. ACE-Step generates the song.
6. Gina copies the returned WAV into `local_ai_uploads\audio`.
7. Gina registers the output as a track and loads it into the Audio Deck automatically.
8. Press Play.
