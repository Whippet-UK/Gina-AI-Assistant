# AIDA64 Complete Gauge Engine v1.9.5

This release adds the complete editable gauge-engine model: physical depth/material controls,
multi-light setup, perspective, reflections, shadows, liquid/CRT/display families, needle motion,
state curves, procedural texture settings, deterministic noise, export-quality controls and a
layer-oriented editor.

The engine model is deliberately data-driven so the renderer can use the same configuration for
preview and every exported state.
