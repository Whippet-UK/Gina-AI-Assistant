# AIDA64 Full Effects Engine v1.9.4

The AIDA64 100-state renderer now applies the extended visual effects during frame rendering, not just as registry names. Effects are state-aware and deterministic. The export path uses the same renderer as the preview, so the 101 PNG states receive the same effect stack.

Implemented effect families include: 3D depth/bevel/inner shadow, reflections, parallax, directional and multi-source lighting, dynamic shadows, specular highlights, liquid/bubbles/turbulence, seven-segment/dot-matrix/ticker/odometer overlays, CRT/scan treatment, heat, electrical arcs, particle/motion/ghost effects, sweep, seeded noise/dither, glare/lens flare, edge glow, ambient occlusion, procedural backgrounds, carbon/brushed-metal textures and gradient backgrounds.
